SLM main: predicted vs actual lesion LOO

The model behind the SLM poster: Multi-task ElasticNet fitted over 296 patients x 199 behavioral and demographic features to 64 left-hemisphere JHU regions, evaluated leave-one-out (max R² = 0.47, 40 of 64 regions above 0.1). Move the sliders to build a behavioral profile and the map shows the lesion pattern the model predicts for it. No patient records are included in this build; unset features sit at the cohort mean.
